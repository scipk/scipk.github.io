Undergraduate Drone Autonomy Research

SDSU SPACE Lab, under Professor Ahmad Bani Younes. Fall 2023 – Summer 2024.

AUTONOMOUS NAVIGATIONPYTHONCOMPUTER VISION (OPENCV)POSE ESTIMATIONROBOTICS & UAV SYSTEMSCONTROLS

Problem

A DJI Tello EDU has a single forward-facing monocular camera and two downward lidars for height. It has no external positioning of any kind. The problem was getting that platform to navigate relative to a visual fiducial — to find a QR code in the camera stream, work out where it is relative to the drone, close to a commanded distance from it, and then execute the instruction encoded in the code itself.

This is where I fell in love with Dynamics and Control.

FIG. 1 — SDSU SPACE LAB

Approach

Everything ran in Python against the Tello SDK, with OpenCV doing the vision. The work built up in three steps, each one flight-tested indoors before the next was added.

COMMANDDrive the airframe from Python over the Tello SDK — takeoff, translation, yaw, land.
DETECTFind and decode the QR fiducial in the monocular camera stream with OpenCV.
POSESolve the fiducial’s apparent shape and size for the position vector from the drone to the code, then close on a commanded standoff distance before executing.

Result

The drone flew under Python command, detected and decoded QR fiducials from its monocular stream, estimated its relative position to a code from that code’s apparent geometry, and closed to a set standoff distance before running the instruction it had read. What did not work: ORB-SLAM3

In mid-2024 I started on ORB-SLAM3, wanting a map to navigate against rather than a single fiducial — the Tello only has monocular forward vision and two downward lidars, so there was no other route to one. The integration failed on tooling, not on theory: the Tello’s Python package and ORB-SLAM3’s Python bindings required incompatible Python versions, and I left the project before resolving it.

I never got SLAM running on this platform, so I do not claim it as working experience. What I took from the attempt was the build and dependency work, and a clear sense of where the integration cost sits in a vision pipeline.
